Política de Privacidade

Agendador de Vídeos — Instrutor Jackson

1. O que é o Agendador

O Agendador de Vídeos é uma ferramenta de uso exclusivo do Instrutor Jackson para publicar e agendar o próprio conteúdo em vídeo no YouTube, TikTok, Instagram, Facebook e LinkedIn. O acesso é restrito ao proprietário; não há cadastro aberto ao público.

2. Dados que coletamos

  • Login no Agendador: endereço de e-mail do proprietário.
  • Contas conectadas: identificador, nome e foto de perfil da conta/página em cada rede, e os tokens de acesso concedidos por ela.
  • Conteúdo: os vídeos, títulos, legendas e horários de publicação enviados pelo proprietário.

3. Como usamos os dados

Os dados são usados apenas para publicar os vídeos nas contas do próprio proprietário, nos formatos e horários escolhidos por ele, e para exibir o status de cada publicação. Não usamos os dados para publicidade, perfis de comportamento ou qualquer outra finalidade.

4. Compartilhamento

Não vendemos nem compartilhamos dados com terceiros. O conteúdo é enviado somente às plataformas que o proprietário escolheu (YouTube, TikTok, Instagram, Facebook e LinkedIn), por meio das APIs oficiais delas. A infraestrutura é hospedada na Supabase e na Vercel.

5. Armazenamento e segurança

  • Tokens de acesso ficam em banco de dados protegido, inacessível pelo navegador.
  • Os vídeos ficam em armazenamento privado e são apagados automaticamente depois de publicados em todas as redes escolhidas.
  • Toda comunicação usa conexão criptografada (HTTPS).

6. Seus direitos e exclusão de dados

A qualquer momento é possível desconectar uma rede na aba Contas, o que apaga os tokens e os agendamentos pendentes dela. Também é possível revogar o acesso diretamente nas configurações de cada plataforma. Para pedir a exclusão completa dos dados, escreva para o contato abaixo; o pedido é atendido em até 30 dias, conforme a LGPD (Lei 13.709/2018).
